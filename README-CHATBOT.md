# Solar Mitr चैटबॉट इंटीग्रेशन

## 📝 ओवरव्यू

इस इंटीग्रेशन में Solar Mitr वेबसाइट पर एक AI-पावर्ड चैटबॉट जोड़ा गया है जो Mistral AI API का उपयोग करके उपयोगकर्ताओं के प्रश्नों का उत्तर देता है। चैटबॉट वेबसाइट के दाहिने निचले कोने में दिखाई देता है और उपयोगकर्ताओं को सोलर एनर्जी सॉल्यूशंस के बारे में जानकारी प्रदान करता है।

## 🛠️ तकनीकी स्टैक

- **फ्रंटएंड**: React.js
- **बैकएंड**: Node.js + Express.js
- **AI इंजन**: Mistral AI API
- **डेटाबेस**: MongoDB (कन्वर्सेशन हिस्ट्री के लिए)

## 🚀 सेटअप निर्देश

### 1. बैकएंड सेटअप

1. सर्वर फोल्डर में जाएँ:
   ```bash
   cd server
   ```

2. आवश्यक पैकेज इंस्टॉल करें:
   ```bash
   npm install
   ```

3. `.env` फाइल कॉन्फिगर करें:
   - `.env.example` फाइल को `.env` में कॉपी करें
   - अपनी Mistral API की और MongoDB कनेक्शन स्ट्रिंग सेट करें

4. सर्वर शुरू करें:
   ```bash
   npm run dev
   ```

### 2. फ्रंटएंड सेटअप

1. फ्रंटएंड फोल्डर में जाएँ:
   ```bash
   cd cosmic-main
   ```

2. आवश्यक पैकेज इंस्टॉल करें:
   ```bash
   npm install
   ```

3. डेवलपमेंट सर्वर शुरू करें:
   ```bash
   npm run dev
   ```

## 🔄 कैसे काम करता है

1. **चैटबॉट इंटरफेस**:
   - वेबसाइट के दाहिने निचले कोने में चैटबॉट आइकन दिखाई देता है
   - आइकन पर क्लिक करने से चैट विंडो खुलती है
   - उपयोगकर्ता संदेश टाइप कर सकते हैं और एंटर या सेंड बटन दबाकर भेज सकते हैं

2. **मैसेज फ्लो**:
   - उपयोगकर्ता का संदेश फ्रंटएंड से बैकएंड API को भेजा जाता है
   - बैकएंड API संदेश को Mistral AI को भेजता है
   - Mistral AI एक प्रतिक्रिया उत्पन्न करता है
   - प्रतिक्रिया बैकएंड से फ्रंटएंड को वापस भेजी जाती है और चैट विंडो में प्रदर्शित होती है

3. **कन्वर्सेशन मैनेजमेंट**:
   - हर चैट सेशन के लिए एक अद्वितीय conversationId उत्पन्न किया जाता है
   - कन्वर्सेशन हिस्ट्री सर्वर पर संग्रहीत की जाती है
   - उपयोगकर्ता चैट विंडो में क्लियर बटन का उपयोग करके कन्वर्सेशन हिस्ट्री को साफ कर सकते हैं

## 🔍 ट्रबलशूटिंग

- **चैटबॉट प्रतिक्रिया नहीं दे रहा है**: सुनिश्चित करें कि बैकएंड सर्वर चल रहा है और `.env` फाइल में सही Mistral API की है
- **API कनेक्शन एरर**: vite.config.js में प्रॉक्सी सेटिंग्स की जांच करें और सुनिश्चित करें कि बैकएंड सर्वर सही पोर्ट पर चल रहा है
- **मैसेज भेजने में त्रुटि**: ब्राउज़र कंसोल में एरर लॉग देखें और सुनिश्चित करें कि API एंडपॉइंट सही हैं

## 🚀 प्रोडक्शन डिप्लॉयमेंट

1. फ्रंटएंड बिल्ड करें:
   ```bash
   cd cosmic-main
   npm run build
   ```

2. बैकएंड को प्रोडक्शन मोड में सेट करें:
   ```
   NODE_ENV=production
   ```

3. सर्वर शुरू करें:
   ```bash
   cd server
   npm start
   ```
